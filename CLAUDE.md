# Lab 6 - Python Algorithm Repository Contribution

@AGENTS.md

## Scope
- Resolve [issue #15655](https://github.com/TheAlgorithms/Python/issues/15655)
- Read `CONTRIBUTING.md` before any edits. Follow all requirements outlined there.

## Repository Boundaries
- Work on the issue in the team's fork. The upstream repository may be used for read-only purposes. Do not alter the upstream repository in any way.

## Agent Workflow
- Use supplied skills to guide the contribution:
    - `resolve-issue` is for analyzing and fixing the issue.
- Delegate triage duties to the `triage` subagent before editing. Use its findings to write tests.
- Apply fix. Address any findings before final validation.
