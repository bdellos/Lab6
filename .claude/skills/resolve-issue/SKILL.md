description: Resolve a specific issue in the Python Algorithm repository.
---
- Given a specific issue number, the agent will reproduce the bug, apply a fix, and validate the solution according to the guidelines in `CONTRIBUTING.md`.
- If the bug cannot be reproduced, the agent will provide a detailed explanation of the steps taken and any findings that may help in resolving the issue.
- Address any findings or additional improvements discovered during the process.
- Draft a pull request title and description that clearly explains changes made. Include the issue number.
